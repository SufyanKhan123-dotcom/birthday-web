
BIRTHDAY WEBSITE PROJECT

Technologies:
HTML
CSS
JavaScript

PROJECT FILES:

1. index.html
   Contains the website structure.

2. style.css
   Contains website design, animations and responsive layout.

3. script.js
   Contains website functionality and interactions.

4. assets
   Contains five birthday memory videos.

VIDEO FILES:

moment1.mp4
moment2.mp4
moment3.mp4
moment4.mp4
moment5.mp4

IMPORTANT:
Keep all video names exactly the same.
Keep videos inside the assets folder.

HOW TO RUN:

1. Open the project folder in VS Code.
2. Open index.html.
3. Right-click index.html.
4. Select Open with Live Server.

CUSTOMIZATION:

- Change balloon messages in script.js.
- Change video titles and descriptions in script.js.
- Change birthday letter text in index.html.
- Change colors and design in style.css.

Responsive design is included for mobile and laptop screens.
